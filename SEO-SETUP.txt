포털 검색 등록용 설정 안내

1. GitHub Pages 배포 후 실제 주소를 확인합니다.
   예: https://아이디.github.io/저장소이름/

2. sitemap.xml의 아래 문구를 실제 주소로 바꿉니다.
   https://lbhbase-web.github.io/kbo-squademaker/

3. Google Search Console
   - 사이트 등록 및 소유권 확인
   - URL 검사에서 메인 페이지 색인 생성 요청
   - 사이트맵에 sitemap.xml 제출

4. 네이버 서치어드바이저
   - 사이트 등록 및 소유 확인
   - 요청 > 사이트맵 제출에서 sitemap.xml 제출

5. Daum 검색등록
   - 사이트 URL 등록 신청

참고: robots.txt는 검색 로봇 접근을 허용하도록 이미 추가되어 있습니다.
index.html에는 검색 설명, robots, Open Graph, canonical, 구조화 데이터 메타 태그가 반영되어 있습니다.
