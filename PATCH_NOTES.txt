KBO 스쿼드메이커 후보 타자 / 중간계투 슬롯 수정 패치

프로젝트 루트에 아래 3개 파일을 덮어써 주세요.
- app.js
- index.html
- bootstrap.js

이번 수정
- 투수 배치는 기존 화면을 유지합니다. 선발 1~5번, 중간계투, 마무리는 원래의 오른쪽 투수 영역에 남습니다.
- 후보 타자 수 선택기는 상단 버튼 줄 바로 아래, 라인업 영역 위에 다시 표시합니다. − / ＋로 4~8명을 선택할 수 있습니다.
- 후보 타자 수와 중간계투 수 합계는 12명이며, 중간계투는 12 - 후보 타자 수로 자동 변경됩니다.
- 설정값은 경기 모드(리그, 스페셜, 랭킹 챌린지, 실시간 매치, 클럽 대전)별로 따로 저장합니다. 기본값은 6명 / 6명입니다.
- 슬롯 수를 줄이려는데 사라질 슬롯에 선수가 배치되어 있으면, 선수를 먼저 비우도록 안내합니다.
- 중간계투 역할 설정은 활성화된 슬롯만 표시합니다.
- 교체 전술 능력치 보너스: 승리조 분업 +3, 승리조 적극적 +2, 추격조 적극적 +2이며 지구력은 제외합니다.
- 기존 투수 화면 배치를 옮기지 않았고, 별도 bullpenBench 영역도 만들지 않았습니다.
- 선수 DB/players.json은 수정하지 않았습니다.

검사
- node --check app.js 통과
- node --check bootstrap.js 통과
- 실제 브라우저에서 런타임 검증은 아직 하지 못했습니다. 배포 후 후보 타자 4명→불펜 8명, 후보 타자 8명→불펜 4명으로 확인해 주세요.
