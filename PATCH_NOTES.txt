KBO LAB 스킬 점수 분포·등급 컷 추가 패치

변경 파일:
- index.html: 계산 결과 아래에 선택한 역할/카드 타입별 등급 컷 표 추가
- kbo-skill-score.js: 등록된 점수표의 유효 스킬 조합을 열거해 상위 확률별 최소 점수 컷 계산
- skill-score-photo-rows.csv: 점수 계산에 사용하는 192개 스킬 행 유지
- kbo-lobby.js: 기존 로비 메뉴/뒤로가기 연결 파일 포함

표시 내용:
- SR+: 상위 0.1% 이내 점수 컷
- SS: 상위 0.5% 이내 점수 컷
- S: 상위 1.5% 이내 점수 컷
- A: 상위 5% 이내 점수 컷
- B: 상위 12% 이내 점수 컷
- C: 상위 12% 초과 구간이며 B 진입 컷 미만으로 표시
- 가능한 조합 수 표시

계산 방식:
- 골든글러브 기준은 6-6-6, 그 외 일반 기준은 6-5-5
- 임팩트는 2개 스킬 점수 합산(화면의 1번 스킬 점수 제외)
- 같은 스킬 계열 중복 조합은 제외하고 동점은 같은 점수로 처리
- 점수 컷은 현재 CSV에 들어 있는 점수와 현재 필터 규칙으로 계산한 경험적 분포임

중요한 한계:
CPBV LAB 원본의 내부 스킬 출현 가중치, 카드 타입별 실제 등장 제한 및 전체 조건 규칙을 모두 확보한 것은 아닙니다. 따라서 추가된 컷은 현재 제공 점수표 기준의 참고 분포이며 원본과 완전히 같은 등급 컷이라고 보장할 수 없습니다.

점수표 행 수: 192 (타자 87, 투수 105)


KBO LAB 일스변·고스변 확률 시뮬레이터 추가

추가/수정 파일:
- index.html: 일스변·고스변을 페이지 안의 시뮬레이터로 연결하고 설정/스킬 옵션 화면 추가
- kbo-lobby.js: 시뮬레이터 화면 전환, 메인 메뉴 복귀, 브라우저 뒤로가기 라우팅 추가
- kbo-skill-simulator.js: 일스변/고스변 확률·역할별 스킬 후보·중복 방지 로직 추가

적용 확률:
- 일스변: 아마추어 30%, 루키 40%, 마이너 23%, 메이저 7%
- 고스변 일반 카드: 1옵 메이저 확정, 2옵/3옵 각각 아마추어 25%, 루키 28%, 마이너 30%, 메이저 17%
- 고스변 국가대표 카드: 1옵 메이저 확정, 2옵/3옵 각각 아마추어 25%, 루키 28%, 마이너 30%, 메이저 7%, 국가대표 10%
- 1옵 잠금: 일스변에서 임팩트·라이브 올스타만 활성화
- 같은 스킬은 3옵션에 중복 배치하지 않음

등급 내 개별 스킬 출현 가중치는 별도 자료가 제공되지 않아, 해당 역할의 후보 스킬 중 균등 추첨하도록 구현함. 후보 스킬은 기존 major-skills.json 및 lower-skills.json을 사용하고, 국가대표 전용 스킬 목록은 프로젝트의 현재 NATIONAL_SKILLS 정의를 기준으로 포함함.

검증: JavaScript 구문 검사 및 HTML 파싱을 통과했고, 적용 확률의 합계는 각 모드에서 100%임. 실행 환경의 브라우저 접근이 차단되어 실제 UI의 전체 상호작용 테스트는 완료하지 못함.
