KBO 스쿼드메이커 불펜 슬롯 위치 수정 패치

수정 파일(프로젝트 루트에 덮어쓰기):
- app.js
- index.html
- bootstrap.js

변경 사항:
- 선발 1~5번과 마무리는 기존 오른쪽 투수 영역에 유지
- 중간계투(RP1~RP6)는 후보 타자(SUB) 슬롯 아래 별도 영역으로 이동
- 불펜 슬롯 역할 라벨(승리조/추격조/롱릴리프) 표시 유지
- 기존 선수 데이터 및 저장 데이터는 수정하지 않음
- 캐시 갱신을 위해 bootstrap/app 버전 문자열 변경

검사: node --check app.js, node --check bootstrap.js 통과.
브라우저에서 실제 실행 테스트는 하지 못했으므로 적용 후 화면 확인 필요.
