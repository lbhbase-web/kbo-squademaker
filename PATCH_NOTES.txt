KBO 스쿼드메이커 v15.4 변경 사항
================================

1. FA 임팩트 / FA 시그니처 기본 능력치
- FA 적용 상태(isFa)가 된 경우에만 타자·투수의 기본 능력치 6개 각각 -3 반영.
- 원본 players.json의 p.stats 값은 변경하지 않음.
- 선수 세부정보, FA 적용된 선수 카드/선택 카드 표시, effectiveStats 및 OVR 계산에 같은 패널티 맵 사용.
- OVR은 6개 능력치의 합계 변화(-18)를 기존 규칙의 floor(totalDelta / 6)에 포함해 계산하므로 자연스럽게 -3 반영. 별도의 OVR -3 패널티는 추가하지 않음.
- FA 대상이 아닌 카드에는 영향 없음.

2. 라인업 가져오기
- 비어 있는 파일, JPEG/PNG, ZIP, PDF를 감지해 구체적인 안내 표시.
- BOM 제거 후 JSON 파싱.
- JSON 문법 오류와 프로젝트에서 지원하지 않는 라인업 구조를 구분해 안내.
- 내보내기 JSON 구조와 기존 importLineupData 검증/복원 로직은 유지.

3. 기존 기능 및 파일 보존
- 기존 선수 데이터, 선수 사진/로고, Firebase/클라우드 라인업, 스킬 데이터 및 런타임 패치 파일은 삭제하지 않음.
- 기존 모바일 선수 선택창 CSS와 Lv.5/Lv.15 포지션 특훈 선택 패치를 유지.
- 홈 화면 시뮬레이터와 선수 세부정보의 스킬 영역은 본 변경에서 임의로 제거하지 않음.

검증
- JSON 데이터 파싱, 참조 경로 및 JavaScript 구문 검사를 수행하도록 준비.
- 실제 Android 브라우저에서의 터치/스크롤과 Firebase 연동, 전체 UI 상호작용은 이 환경에서 실기기 테스트하지 않음.
