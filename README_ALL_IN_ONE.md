기존 선수 카드 **8,982장**과 기능을 유지한 채 HTML 경량화, 선수 데이터 분리, 야구장 이미지 파일 형식 수정, sitemap 추가를 적용한 버전입니다.

# KBO SquadMaker ALL-IN-ONE

이 폴더는 현재 스쿼드메이커 통합 실행본입니다.

## 바로 실행
- `index.html`이 메인 사이트입니다.
- `baseball-field.png`는 라인업 야구장 배경입니다.
- 별도 빌드 명령 없이 정적 사이트로 사용할 수 있습니다.
- Vercel에 이 폴더 전체를 업로드하면 정적 사이트로 배포할 수 있습니다.

## 현재 프로젝트에서 유지해야 할 핵심
- 전체 선수카드 데이터 및 기존 카드 종류 보존
- LIVE / LIVE 올스타 / 임팩트 / 시그니처 / 국가대표 / 골든글러브
- 선수 검색, 구단/포지션/카드 종류 필터
- 타자 우타/좌타/양타, 투수 우투/좌투 선택
- SP1~SP5, RP1~RP6, CP
- 불펜 역할/전술
- 포지션 특훈 Lv.10/Lv.20 및 스킬 등급 확률
- 시즌카드 커스텀, 강화/훈련/특훈
- 라인업 저장/불러오기
- LIVE 시즌/올스타 세트덱 규칙
- FA 카드 팀 로고 규칙
- 모든 카드 선수명 흰색, 검은 글자 그림자 제거
- 시그니처 5성 별 빨강핑크(#ff1744) + 흰 외곽 효과
- PC/태블릿/모바일 동일 계산 규칙

## 중요
새로 단순한 사이트를 만드는 대신 `index.html`에 들어 있는 기존 데이터와 기능을 기반으로 수정해야 합니다. 기존 기능이나 데이터를 임의로 삭제하지 마세요.
