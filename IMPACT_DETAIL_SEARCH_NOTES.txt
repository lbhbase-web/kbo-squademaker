KBO 스쿼드메이커 - 임팩트 상세 검색 UI 패치

수정 파일:
- app.js
- index.html
- bootstrap.js

변경 사항:
- 선수 검색창에서 선수 종류 '임팩트'를 선택하면 '임팩트 상세 검색'이 펼쳐집니다.
- 2025 TOP3와 2026 TOP3를 별도로 선택할 수 있습니다. TOP3의 year 값 25/2025 및 26/2026과 series=TOP3를 기준으로 필터링합니다.
- 기존 데이터에 존재하는 임팩트 시리즈도 세부 선택 버튼으로 표시됩니다.
- 세부 선택은 한 번에 한 종류이며, 같은 버튼을 다시 누르거나 '×'를 누르면 세부 필터가 해제됩니다.
- 선수 데이터(players.json)는 변경하지 않았습니다.
- bootstrap/app 캐시 버전을 갱신했습니다.

검증:
- app.js / bootstrap.js Node 문법 검사 통과
- players.json JSON 파싱 확인
- ZIP 무결성 검사 수행
- 실제 브라우저에서 클릭 동작 검증은 미수행
