컴프야V26 스쿼드메이커 - 백투백 홈런 스킬 추가 패치
대상 파일: app.js
기존 데이터/기능을 삭제하지 말고 아래 두 곳만 수정.

1) const MAJOR_SKILLS 배열 안에 아래 항목을 추가
(배열의 다른 객체와 쉼표로 구분)

{"id":"m_backtoback_B","name":"백투백 홈런","role":"B","tier":"major","keys":["all"],"values":[1,1,1,2,2,3,3,4,4,5],"modeKeys":["power","contact"],"modeValues":[2,3,3,4,5,6,7,8,9,10],"modes":["club"]}

- 기본 효과: 타자 모든 능력치 +1/+1/+1/+2/+2/+3/+3/+4/+4/+5 (Lv1~10)
- 클럽 대전에서 파워·정확 추가 +2/+3/+3/+4/+5/+6/+7/+8/+9/+10
- '직전 타자가 홈런을 쳤다면 상대 투수 구위·제구 감소'는 경기 상황에 따라 적용되는 상대 능력치 감소 효과임.

2) function conditionalSkillEffectLines(d,n,p,slot,mode=currentMode) 함수 안에서
const add=(s)=>{if(s)lines.push(s)}; 바로 다음에 아래 코드를 추가.
이 코드는 Lv1~10 모두에서 효과 설명을 표시한다.

 if(d.id==='m_backtoback_B'){
  const pitcherDown=[10,10,10,10,12,12,12,14,14,14][lv-1];
  const clubExtra=[2,3,3,4,5,6,7,8,9,10][lv-1];
  add(`타자의 모든 능력치 +${[1,1,1,2,2,3,3,4,4,5][lv-1]}`);
  add(`직전 타자가 홈런을 쳤다면: 상대 투수 구위·제구 -${pitcherDown}`);
  if(mode==='club') add(`클럽 대전: 파워·정확 추가 +${clubExtra}`);
  return lines;
 }

주의:
- 이 패치는 스킬 선택 목록, 기본 타자 능력치 증가, 클럽 대전 추가 증가, 상세 설명을 등록한다.
- '직전 타자가 홈런' 조건은 실제 경기 중 상황을 앱이 추적하지 않으므로 자동 능력치 합산으로 구현하지 않고 조건부 효과 설명으로 표시한다.
- 기존 스킬 배열의 마지막 항목 뒤에 쉼표를 넣고 새 객체를 추가해야 한다.
- 수정 후 브라우저 콘솔 오류가 없는지 확인하고, 스킬 상세에서 레벨 1~10 값과 클럽 대전 추가 효과를 확인한다.
