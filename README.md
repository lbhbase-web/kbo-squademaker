## GitHub Pages 실행
1. 이 ZIP의 압축을 풉니다.
2. GitHub에서 Public 저장소를 만들고 Add file → Upload files를 누릅니다.
3. ZIP 자체가 아니라 압축을 푼 파일들을 올립니다. index.html이 저장소 첫 화면에 있어야 합니다.
4. Commit changes로 저장합니다.
5. Settings → Pages → Source에서 Deploy from a branch를 선택합니다.
6. main 브랜치와 /(root)를 선택하고 Save를 누릅니다.
7. 게시가 끝나면 같은 Pages 화면의 Visit site 주소로 접속합니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
