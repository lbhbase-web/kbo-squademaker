# 컴프야 V26 최신 통합본 · 8,697장

최신 저장 사이트 버전을 바탕으로 선수 상세창을 수정했습니다.
- 추가 101장 포함: 26 올스타 51장, 좌타 해결사 50장
- 커스텀 선수 생성·수정·삭제·백업 불러오기/내보내기 포함
- 불펜 RP1~RP6 각각의 역할을 승리조/추격조/롱릴리프로 변경하여 인원수 배분
- 카드 종류별 지정 훈련, 기존 각성·특훈 수정, 불펜 역할 및 최신 라인업 화면 포함
- 상세창: 최종 능력치 (기본값+증가량), 훈련·특훈·포지션 특훈을 구분해서 표시
- 훈련·특훈·포지션 특훈 레벨 입력 및 0/최대 버튼
- 능력치별 수치는 실제 계산 결과 표시. 수동 배분·FA 설정은 하단 추가 설정에서 변경
- 중앙 흰색 상세창에 기존 선수 카드 미리보기, 최종 능력치(기본값+증가량), 훈련/특훈/포지션 특훈을 표시
- 각 능력치 입력칸은 총 배분 한도 내 수정 가능. 다른 능력치를 먼저 낮추면 남은 수치를 배분할 수 있습니다.
- 강화·각성 및 기존 세부 설정은 접이식 메뉴에 있습니다.
- 코드 문법/데이터 검사는 완료했으나 실제 브라우저 시각 검증은 하지 못했습니다.
