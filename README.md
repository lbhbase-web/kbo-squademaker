## 선수 투타 자동 적용
KBO 공식 프로필 기반 조사 데이터를 사용해 확인 가능한 선수의 우타/좌타/양타 및 우투/좌투를 기본값으로 적용했습니다. 양손 타격 선수는 양타로 설정되며, 육성 화면에서 수동 변경할 수 있습니다. 자세한 출처는 `HANDEDNESS-SOURCE.txt`를 참고하세요.

## 가명 선수 투타 매칭
- 한국인 가명은 성 + 이름 초성 패턴, 외국인 가명은 첫 글자 + 팀/연도/포지션 패턴을 이용해 실제 선수를 확인합니다.
- 확인된 가명: 오전익→오재원, 임총오→임창용, 호스틴→호세, 데니스→데이비스, 테런스→테임즈.
- 가명은 실제 선수의 좌/우/양타 및 좌/우투 정보를 자동 적용합니다.

## 투타 수동 선택 (2026-09-24)
검색/가명 매칭으로 투타가 확인되지 않는 선수는 육성창의 `투타 설정`에서 직접 고를 수 있습니다. 타자는 우타/좌타/양타, 투수는 우투/좌투를 지원합니다. 커스텀 선수 생성 시에도 동일하게 선택할 수 있습니다. 오전익→오재원, 임총오→임창용, 호스틴→호세, 데니스→데이비스, 테런스→테임즈 가명 연결이 포함되어 있습니다.
