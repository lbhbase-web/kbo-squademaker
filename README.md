# 컴프야 V26 스쿼드 메이커 · 최신 통합본

이 ZIP은 지금까지 요청한 수정사항을 한 번에 합친 최신본입니다.

## 포함된 주요 수정
- 기존 야구장형 라인업 화면 유지
- 10개 구단 로고를 카드 우측 상단에 표시하고, 로고는 index.html 안에 인라인으로 포함
- 선수 DB: 기존 데이터 + 소방수 40장 + 26 LIVE V1 221장 + 2026년 9월 국가대표 24장
- 최신 전체 선수 데이터: 8,982장 (`players_8982.json`)
- 국가대표 24장 별도 목록: `added_national_2026_sep_24.json`
- 투수 우투/좌투 선택, 타자 우타/좌타/양타 선택
- 포지션 특훈 10/20레벨 스킬 3개 랜덤
  - 메이저 10%
  - 마이너 30%
  - 루키 30%
  - 아마추어 30%
  - 동일 스킬 중복 방지
- 스킬 좋은 순서: 메이저 → 마이너 → 루키 → 아마추어
- 색상: 메이저 보라 / 마이너 파랑 / 루키 초록 / 아마추어 회색
- 최종 능력치에 바로 합산할 수 없는 경기 중 조건부 스킬은 상세창 아래에 별도 안내
- 불펜 RP1~RP6 역할 설정
  - 승리조 / 추격조 / 롱릴리프
  - 기본 3 / 2 / 1
  - 승리조·추격조 최소 1명, 각 역할 최대 4명, 롱릴리프 0명 가능
- 불펜 교체 전술
  - 승리조: 분업 / 적극적 / 기본
  - 추격조: 적극적 / 기본
  - 승리조 분업 조건 충족 시 지구력 제외 투수 능력치 +2
  - 승리조 적극적 +1
  - 추격조 적극적 +1
- 불펜 역할/전술, 육성, 스킬 등 라인업 내보내기/가져오기에 저장
