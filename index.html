적용한 육성 규칙
선수 DB: 기존 8,379장 전체 DB + 사용자 제공 GIF/스크린샷 카드 217장 = 8,596장 반영 · 중복 카드 유지 · 임팩트 연도 없음 · 전 카드 6스탯 입력
임팩트 종류: 엑셀 기준 총 52종을 그대로 반영. 여름사나이·가을사나이·저니맨·난세의 영웅 등 포함. “지니어스”, “번개의 영웅”은 새 파일에 없어서 제거.
OVR 계산: 원본 6스탯 대비 최종 능력치의 합이 +6 될 때마다 OVR +1. +12면 +2, +18이면 +3. 반대로 총 -6이면 OVR -1. 훈련·강화·각성·특훈·포지션 특훈·라인업/세트덱 효과·역시너지를 모두 합산해서 계산.
포지션 배치: LF→LF, CF→CF, RF→RF, 3B→3B, SS→SS, 2B→2B, 1B→1B, C→C, DH→모든 타자. SUB1~6은 타자 후보 슬롯.
구단 로고: KIA·삼성·LG·두산·롯데·한화·SSG·NC·KT·키움의 실제 구단 로고 이미지를 카드 오른쪽 위에 표시. K/S 같은 임시 글자 표시는 제거.
선수카드 디자인: 게임 카드 형태로 표시. 상단 성급 별, 왼쪽 위 OVR, 그 아래 강화/각성, 오른쪽 위 소속팀 로고와 포지션, 중앙 선수 사진, 하단 선수명. 임팩트는 이름 위에 여름사나이·가을사나이 등 세부 종류, 시그니처·국가대표·골든글러브 등 연도 카드에는 이름 옆에 연도 표시.
PC/모바일 화면: 처음에는 기기 폭에 맞춰 자동 표시되고, 오른쪽 아래 버튼으로 언제든 PC↔모바일 전환 가능. 선택한 화면은 다음 실행에도 기억됨.
선수 선택: 선수 전체 목록은 숨김. 라인업 포지션 칸을 누르면 해당 포지션 선수만 열리며, 선택창에서 팀과 카드종류를 동시에 필터 가능. 골든글러브·국가대표·시그니처·라이브·라이브 올스타·임팩트를 구분 표시.
국가대표 와일드카드 제한: 모든 모드에서 국가대표 와일드카드를 라인업당 최대 2장. 3번째 카드는 배치할 수 없음.
국가대표 와일드카드: 육성창에서 국가대표를 와일드카드로 변경 가능. 변경 시 OVR -3 및 기본 6능력치 각각 -3, 특훈은 1에서 시작해 최대 7(추가 6회), 강화는 국가대표 5성 강화표를 그대로 사용. 이번에 받은 각성표를 적용해 9각 누적 총 +24. 잠재력 슬롯 효과는 계속 제외.
성급: 올스타·시그니처·국가대표는 5성, 임팩트는 4성. 골든글러브는 이번에 받은 4성 도감 스크린샷의 87장만 4성으로 고정하고 나머지는 5성. 라이브는 성급 미입력으로 두어 3/4/5성 세트덱 효과 판정에서 제외.
역시너지 면제: 골든글러브는 세트덱 팀 카드 1장까지만 역시너지 카운트에서 제외. 라이브 올스타도 세트덱 팀 카드 1장까지만 역시너지 카운트에서 제외.
라인업별 역시너지: 실시간 매치=골글 5/-2, 6/-4, 7+/-6 · 올스타 4/-3, 5+/-6. 랭킹 챌린지·클럽 대전=골글 6/-2, 7/-4, 8+/-6 · 올스타 4/-3, 5+/-6. 리그 모드·스페셜 매치=골글 7/-2, 8/-4, 9+/-6 · 올스타 5/-3, 6+/-6. 골글/올스타 역시너지가 동시에 발생하면 두 패널티를 합산해 모든 선수 모든 능력치에 적용.
세트덱 효과: 선택한 30~200점 효과를 최종 능력치에 실제 반영. “선택 선수/연도/팀” 효과는 해당 점수 아래에 뜨는 선택 메뉴로 대상을 지정.
투수 역할 고정: SP는 SP1~SP5만, RP는 RP1~RP6만, CP는 CP만 가능. 선발↔불펜↔마무리 간 이동은 불가.
포지션 특훈 보너스: Lv.5와 Lv.15에서 각각 1회 발생. 게임처럼 6개 능력치 중 1개와 +1~+3을 랜덤으로 뽑을 수 있고, 스쿼드 메이커에서는 실제 보유 결과를 맞추기 위해 능력치와 상승량을 직접 선택하는 것도 가능. “랜덤 재추첨”을 누르면 새 결과가 나오고, 드롭다운을 바꾸면 직접 선택한 값으로 즉시 적용됨. 20레벨은 기본 36 + 보너스 2~6으로 총 38~42. Lv.10·Lv.20 스킬은 적용하며, 랜덤 등급 확률은 메이저 10% · 마이너 30% · 루키 30% · 아마추어 30%.
포지션 특훈 단계표: 첨부 GIF 27프레임을 느리게 확인해 C·1B·2B·3B·SS·LF·CF·RF·DH·SUB1~6·SP1~5·RP1~6·CP의 1~20레벨 상승치를 각각 반영. 모든 슬롯 기본 합계는 20레벨 36, Lv.5/+3 및 Lv.15/+3 보너스 포함 최대 총합 42.
선수 중복: 같은 이름의 선수는 카드 종류·연도·포지션이 달라도 한 라인업에 1명만 사용 가능. 선발·DH·후보 포함 전체 슬롯에 적용.
훈련 최대: 시그니처 25 / 골든글러브 25 / 임팩트 18 / 국가대표 22 / 라이브 올스타 30. 훈련 1레벨마다 6개 능력치 중 3개가 각각 +1.
강화: 0~10강.
강화 능력치: 이번 스크린샷에서 확인한 라이브 올스타 5성, 골든글러브 5성/4성, 국가대표 5성, 시그니처 5성, 임팩트 4성의 +1~+10강 단계별 능력치 상승을 실제 최종 능력치에 누적 반영. 시그니처와 임팩트는 FA 여부와 관계없이 같은 강화표를 사용. 10강 누적 합계는 라이브 올스타/국가대표/시그니처 130, 골든글러브 5성 136, 골든글러브 4성 76, 임팩트 4성 70. 라이브 강화표는 아직 자료가 없어 미적용.
각성 지원 카드(임팩트·시그니처·골든글러브·국가대표)는 0~9각. 라이브·올스타는 각성 불가.
각성 능력치: 스크린샷에서 확인한 골든글러브, FA 임팩트, FA 시그니처, 국가대표 와일드카드의 타자/투수 1~9각 기본 능력치 상승을 실제 최종 능력치에 누적 반영. 9각 총합은 FA 임팩트 +15, FA 시그니처 +27, 국가대표 와일드카드 +24, 골든글러브 +36. 잠재력 슬롯 추가/개방 효과는 구현하지 않음. 국가대표·비FA 임팩트/시그니처는 각성 가능하며, 세부 각성 능력치 표가 없는 유형은 자료를 받기 전까지 능력치 보너스만 미적용. 라이브·올스타는 각성 자체가 불가.
특훈: 국가대표 4~8 / 시그니처 5~8 / 임팩트 4~7 / 골든글러브 3~6.
FA 임팩트 1~5 / FA 시그니처 2~7. 임팩트·시그니처의 원소속 팀 배지를 눌러 다른 구단으로 바꾸면 FA로 취급.
임팩트는 연도 없는 카드로 처리하고 모든 선택 연도 효과의 대상이 돼.
라인업 모드별 카드 구성 조건을 만족하면 모든 선수/타자/투수 능력치 +1 효과가 실제 최종 능력치에 적용돼. 골든글러브·올스타 최대 장수 조건은 현재 제한 판정만 표시하고 별도 능력치 보너스는 없어.
골든글러브는 카드의 실제 연도/원소속팀과 무관하게 현재 선호구단의 팀 효과 대상으로 처리돼.
선호구단과 현재 소속이 같은 국가대표·시그니처·임팩트(FA 포함)는 선택한 능력치 1개에 기본 특훈 값 대비 증가분이 적용돼. 기본 선택은 타자 파워, 투수 구위야. 골든글러브도 같은 방식으로 선택 능력치 1개에 적용해.
훈련은 자동/수동 분배를 지원하고 1레벨당 선택된 3개 능력치가 각각 +1로 실제 반영돼. 강화와 각성은 확인된 카드 유형의 표만 실제 능력치에 반영하고, 사진에 없는 유형은 레벨만 저장해. 특훈은 선택한 능력치 1개에만 실제 반영돼. 포지션 특훈은 모든 슬롯 기본 20레벨이며 20레벨 총합 +42가 라인업에 추가돼.
