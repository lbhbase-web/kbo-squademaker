포함 파일: app.js, index.html

적용 방법:
1. 기존 저장소를 백업합니다.
2. 저장소에서 app.js와 index.html이 있는 위치에 이 두 파일을 같은 경로로 덮어씁니다.
3. 커밋/배포 후 브라우저를 새로고침해 확인합니다.
